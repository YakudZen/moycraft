# Проверка первого этапа

Дата: 17 сентября 2026.

## Выполнено

- Все C#-файлы, включая редакторские команды и проверки, скомпилированы с библиотеками установленной Unity 6000.5.0f1, языком C# 9 и профилем .NET Standard 2.1.
- Выполнены 24 проверки настоящих управляемых методов проекта: заполнение/переполнение панели, стаки, расход, слоты инструментов, выбор слотов, ограничения тиров, скорость добычи, отрицательные координаты и направление шести граней.
- Для чистой логики объекты создаются без вызова Unity native-конструкторов. Движок и физика не подменяются; соответствующие проверки так не выполнялись.

## Пока не выполнено

- Импорт и запуск сцены в редакторе.
- Проверки настоящих MeshCollider, стыков чанков и перемещения персонажа.
- Визуальная проверка HUD, текстур и мира.
- Сборка Windows и запуск её smoke-теста.

Запуск Unity из автоматизированной среды дважды остановился до компиляции: служебные каталоги и запуск/IPC Unity Package Manager оказались недоступны. Автоматическое управление окном Unity Hub также не дало проверить проект. Это ограничение текущего способа запуска; работоспособность редакторской сцены пока не подтверждена.

## Как завершить проверку

1. Открыть проект в Unity Hub с версией 6000.5.0f1, дождаться импорта. При первом импорте сцена и ассеты генерируются автоматически.
2. Выполнить **Voxel Survival → Run foundation checks**.
3. Нажать Play: проверить мышь, ходьбу, прыжок, добычу камня киркой, установку и переход через границу чанка.
4. Построить небольшое укрытие, уйти за дальность загрузки и вернуться. Постройка должна сохраниться в текущем запуске.
5. Выполнить команду сборки из README и запустить `-smokeTests`.

Нельзя считать первый этап полностью принятым до этих проверок. Дисковые сохранения и остальные системы MVP ещё не входят в этот этап.
