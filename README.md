# Moycraft

Moycraft — тестовое название моей воксельной 3D-песочницы на Unity.

## Первый этап: основа мира

Проект для **Unity 6000.5.0f1** с Built-in Render Pipeline. Внешние ассеты и платные пакеты не требуются.

### Запуск в Unity

1. Добавьте эту папку через Unity Hub → Add project from disk.
2. После первой компиляции проект автоматически создаст и откроет сцену `Assets/Scenes/Prototype.unity`, каталог блоков и материалы. Повторно открыть её можно через **Moycraft → Create or open prototype**.
3. Нажмите **Play**, затем щёлкните по игровому окну для управления.

### Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD |
| Обзор | Мышь |
| Бег | Левый Shift |
| Прыжок | Space |
| Добыча | Удерживать ЛКМ |
| Установка блока | ПКМ |
| Выбор слота | 1–9 / колёсико |
| Пауза / курсор | Esc |

В панели есть стартовые блоки, один свободный слот и две кирки в слотах 8 и 9. Камень требует кирку первого тира. Трава даёт землю. Строить внутри персонажа нельзя; заполненная панель блокирует добычу. Нижний слой мира защищён от разрушения.

### Реализовано

- Чанки 16 × 64 × 16 и загрузка вокруг персонажа; один новый чанк за кадр.
- Одна сетка и один MeshCollider на чанк, без игрового объекта на каждый блок.
- Исключение закрытых граней, корректные стыки и отрицательные координаты.
- Генерация рельефа по seed: трава, земля, камень.
- Деревья из дерева и листвы, связанные пещеры с выходами на поверхность.
- Выбор блока прямым проходом луча через сетку, без зависимости от коллайдера чанка.
- Персонаж от первого лица с коллизиями, гравитацией, бегом и прыжком.
- Выделение блока, постепенная добыча с учётом инструмента, установка.
- Панель на 9 слотов, стаки до 64, получение и расход блоков.
- Описания всех согласованных типов блоков: `Assets/Data/Blocks`.
- Пауза и сохранение изменений в памяти при выгрузке чанков.

**Это первый этап, а не весь MVP. Сохранений на диск пока нет:** остановка Play или выход из игры удаляет изменения мира. Освещение дневное и статичное. Вода, лава и огонь пока описаны в каталоге, но их симуляция и размещение отключены. Лёд отображается непрозрачным, песок и гравий не падают.

### Настройка

В сцене на объекте **Prototype bootstrap** задаются seed и дальность чанков. В asset каждого блока задаются постоянный ID, текстуры граней, прочность, инструмент, минимальный тир, выпадение и параметры горения. Уже используемые ID нельзя переименовывать по смыслу или назначать другим блокам после появления формата сохранений.

Тип блока занимает один байт на ячейку. Общие характеристики находятся в каталоге; изменённые ячейки хранятся отдельно. Временный прогресс добычи сбрасывается при смене цели или инструмента. Память изменений растёт с числом отредактированных ячеек; дисковое хранение и ограничение памяти относятся к следующему этапу.

### Проверки и сборка

В редакторе: **Moycraft → Run foundation checks**. Проверяются seed, отрицательные координаты, скрытые грани, стыки, коллайдеры, выгрузка/загрузка, границы мира, тировые ограничения и переполнение панели.

Проверка C# и 46 проверок чистой логики без запуска редактора (нужен установленный .NET SDK): `./Tools/Check-Source.ps1`. Они проверяют инвентарь, инструменты, координаты, направление граней, выбор блока и генерацию; они не заменяют проверки физики и изображения в Unity.

После обновления остановите и заново запустите Play либо пересоберите приложение. Генератор версии 2 меняет рельеф для прежнего seed и добавляет деревья и пещеры. Дальность взаимодействия остаётся 5 блоков; требования к инструментам сохраняются.

Статус проверки текущего этапа описан в [docs/VALIDATION.md](docs/VALIDATION.md).

Из PowerShell в корне проекта:

```powershell
& 'C:/Program Files/Unity/Hub/Editor/6000.5.0f1/Editor/Unity.exe' -batchmode -nographics -quit -projectPath "$PWD" -executeMethod VoxelSurvival.Editor.ProjectSetup.ValidateAndBuild -logFile "$PWD/build.log"
```

Сборка создаётся в `Builds/Windows/Moycraft.exe`. Переменная окружения `VOXEL_BUILD_PATH` позволяет указать другой путь к exe. В уже открывавшемся проекте название продукта обновится после компиляции скриптов; существующий exe нужно пересобрать.

Для проверки запуска, движения, прыжка, взаимодействия и коллизий в готовой сборке:

```powershell
./Builds/Windows/Moycraft.exe -smokeTests -smokeOutput "$PWD/Builds/Smoke" -logFile "$PWD/Builds/runtime.log"
```

Проверка создаёт `runtime-results.json` и снимок `prototype.png`, затем закрывает приложение. Код выхода 0 означает успех. Автопроверки запускайте отдельно от обычной игры.
